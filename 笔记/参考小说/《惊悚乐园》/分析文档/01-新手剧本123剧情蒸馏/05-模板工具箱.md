## 一、剧本结构模板

### 1.1 新手教程剧本模板（3章结构）

**适用场景**：主角首次进入游戏世界，需要完成基础教学

```

## 功能定位
- 建立主角核心设定（特殊能力/异常状态）
- 展示角色性格细节
- 引入世界观基础
- 设置悬念钩子

## 内容清单
□ 主角登录/进入游戏过程
□ 核心设定自然展示（通过行为而非旁白）
□ 角色创建（昵称/形象）

□ 游戏模式选择
□ 悬念结尾（进入核心场景前的钩子）

## 节奏控制
- 前半：静态铺垫（阅读、选择、创建）
- 后半：突然加速（进入游戏场景）

- 恐怖/挑战体验

- 获得关键能力/道具

□ 初始环境探索

□ 第一个机制教学点（在需要时出现）
```

## 二、场景写作模板

### 2.1 恐怖场景模板

#### 渐进式恐怖场景

```
【环境铺垫】（视觉+听觉+嗅觉综合）
- 视觉：光线状态、可见范围、异常物体
- 听觉：背景音、异常声响、寂静程度
- 嗅觉：气味暗示（腐败、消毒水、血腥等）

【心理铺垫】（暗示即将发生异常）
- 环境描述中的违和感
- 常人应有反应的铺垫
- 主角的异常反应对比

【恐怖事件触发】（渐进升级）
第一阶段：轻微异常（声音/光影变化）
第二阶段：明显异常（物体移动/形象闪现）
第三阶段：直接威胁（实体出现/追击开始）

【主角反应】（符合角色设定）
- 冷静分析（智力型主角）
- 即时应对（行动型主角）
- 反差幽默（缓解紧张）

【过渡或延续】
- 进入追逐/战斗
- 转入选谜/探索
- 章节结束钩子
```

**原文示例结构**（第002章电梯场景）：
```
环境铺垫：电梯内漆黑、只有呼吸声
心理铺垫：正常人会惊慌，但封不觉冷静
第一阶段：灯光闪一秒，镜中见血影
第二阶段：电梯门开，腐败气味，走廊显现
第三阶段：血爪袭来，血尸登场
主角反应：缩脖子躲避，冷静分析逃跑路线
过渡：开始走廊追逐
```

#### 突然式恐怖场景

```
【平静状态】（降低警惕）
- 看似安全的环境
- 角色专注于某事（解谜、对话）
- 读者/玩家的注意力被引导

【触发点】（精心设计的惊吓）
- 视觉：突然出现、角度刁钻
- 听觉：尖叫、巨响、静音后的突发声音
- 触觉：被触碰、被抓住

【即时反应】（短暂混乱）
- 生理反应（惊吓值上升）
- 即时动作（后退、尖叫、防御）
- 快速恢复（游戏角色）或持续恐慌（恐怖作品）

【后续发展】
- 进入战斗/逃跑
- 发现是虚惊（但铺垫了真实威胁）
- 揭示新的信息
```

### 2.2 解谜场景模板

```
【谜题呈现】
├─ 环境线索：异常物体、图案、文字
├─ 规则说明：系统提示或剧情物品说明
├─ 限制条件：时间、资源、能力
└─ 目标明确：打开门锁/获得物品/通过区域

【调查过程】
├─ 系统化扫描环境
├─ 线索发现与记录
├─ 假设形成
└─ 初步验证

【推理展示】（内心独白或队友讨论）
├─ 线索整合
├─ 逻辑链条构建
├─ 排除错误选项
└─ 确定解决方案

【解决方案执行】
├─ 操作步骤（可能有时间压力）
├─ 成功验证
└─ 奖励获得（道具/通路/信息）

【隐性解法设计】（可选但更优）
├─ 表面解法：直接但代价高
├─ 隐性线索：需要洞察力发现
├─ 创造性解决：利用环境或物品组合
└─ 更好奖励或无损通过
```

**原文示例**（第012章灯管解谜）：
```
谜题：需要15kg开启门，可用猴子(10kg)或椅子+玩偶(7.5kg)
隐性线索：重量精确到小数点后一位，暗示可组合
关键发现：天花板上的荧光灯可被拆卸
解决方案：西服当绳索→拉下灯管→碾碎增加重量→不杀猴过关
```

### 2.3 对话场景模板

#### 队友对话

```
【角色A发言】（基于性格和当前情境）
├─ 信息传递
├─ 情绪表达
└─ 性格展示

【角色B回应】（符合关系定位）
├─ 信息回应或补充
├─ 情绪共鸣或对比
└─ 推动对话继续

【互动发展】
├─ 讨论决策
├─ 分工协作
└─ 性格碰撞（幽默或冲突）

【对话收尾】
├─ 达成共识
├─ 行动开始
└─ 留下悬念/钩子
```

**原文示例**（第006章）：
```
封不觉（推理者）：提出两种选择，分析利弊
王叹之（执行者）：直接选择第二种（即使没听全）
互动：分工看病历和素描
发展：解谜路线确定
```

#### 系统提示对话

```
【系统提示】（正式、简洁、结构化）
【角色反应】（吐槽、分析、确认）
【行动继续】（根据提示执行操作）
```

**原文示例**：
```
系统：【备注：我想你知道该怎么做。】
角色反应："封不觉感觉这物品的备注栏恶意满满"
行动：继续查看属性并使用
```

## 六、模板定制建议

### 6.1 根据作品类型调整

**恐怖向作品**：
- 增加感官描写比重
- 延长恐怖升级过程
- 减少幽默元素密度

**解谜向作品**：
- 强化解谜场景模板
- 增加线索关联复杂度
- 设置更多隐性解法

**角色向作品**：
- 增加对话场景比重
- 强化角色反应个性化
- 通过互动展示关系

### 6.2 根据目标读者调整

**新手读者**：
- 机制说明更详细
- 线索呈现更明显
- 节奏控制更舒缓

**资深读者**：
- 减少基础说明
- 增加隐性内容
- 允许更高复杂度
