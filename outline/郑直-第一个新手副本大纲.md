# 郑直 - 第一个新手副本：《八楼镜影》大纲

**剧本类型**：新手教程（单人）
**核心主题**：恐怖追击+物理破解+直觉破局
**教学机制**：生存值、体能值、惊吓值、技巧值、基础物品系统

---

## 第一章：直觉侦探进入游戏

### 章节功能
- 展示郑直核心设定
- 自然引入游戏世界观
- 设置悬念钩子

### 内容大纲

1. **现实引入**
   - 郑直退役后在家写推理小说，陷入情节瓶颈
   - 发小推荐《惊悚乐园》，说这个沉浸式游戏能找灵感
   - 郑直抱着试一试的心态进入游戏舱

2. **游戏登录**
   - 系统加载完成，弹出用户协议
   - 常人会直接点"我同意"，郑直却认真逐字阅读，还在现实小本本上记重点（符合他认真一根筋的性格）
   - 系统提示创建角色，郑直输入昵称"直觉侦探"，对这个笔名非常满意
   - 系统初始属性评估：
     - 身体能力：S级（基于前职业摔角选手背景）
   - 推理能力：E级（系统评估，郑直表示强烈反对）
   - 直觉能力：A级（系统认可，郑直表示这才对嘛）

3. **进入教程**
   - 系统提示新手教程即将开始，传送进入电梯
   - 电梯上行，突然停在八楼
   - 灯光毫无征兆熄灭，一个低沉的声音响起：
     > "欢迎来到惊悚乐园...小心镜子..."
   - 电梯开始轻微摇晃，章节结束，留下悬念

---

## 第二章：镜影追击与密码破锁

### 章节功能
- 核心机制教学（四值系统）
- 展示郑直错误推理+物理破解特色
- 推进剧情，向最终场景过渡

### 内容大纲

1. **环境引入**
   - 电梯门缓缓打开，扑面而来灰尘和霉味
   - 视觉描写：古旧旅馆八层走廊，两侧挂满落地镜，地毯老旧发黑，走廊尽头一扇房门半开着
   - 渐进式恐怖：郑直呼吸正常，系统提示首次弹出四值介绍：
     - 【这是您的生存值，以百分比显示...当前生存值：100%】
     - 【这是您的体能值，具体数值可见...当前体能值：100/100】
     - 【这是您的惊吓值...当前惊吓值：3%】
     - 【这是您的技巧值...当前技巧值：0】
   - 郑直看完系统提示，淡定评价："哦，和我想的差不多，就是个大型真人推理游戏"

2. **怪物登场**
   - 郑直走到第一面镜子前，仔细观察
   - 突然，镜中的自己动了——缓缓转身，变成一个全身漆黑的人形影子
   - 黑影从镜子里一点点爬出来
   - 常人反应对比：换作普通玩家此时惊吓值至少飙升50%，郑直反而站定，摸着下巴开始推理：
   - **中二宣言**："以我直觉侦探的名义起誓，真相只有一个！这一定是旅馆老板谋害房客后，怨念附在镜子里！"（典型的错误推理）
   - 黑影发出低沉呼啸，开始加速追击

3. **追击过程**
   - 郑直转身就跑，体能值开始下降
   - 郑边跑边观察，尝试挥拳攻击黑影，伤害微弱（系统提示：黑影免疫常规物理攻击，需要找到特定方法）
   - 走廊两侧共有四个房门，都锁着，只有墙上镜子里的影子在不断逼近

4. **解谜过程（郑直特色版）**
   - 第一扇门：四位数密码锁，锁旁边有几句模糊的提示文字，郑直看不懂逻辑，排列组合试了两次都不对
   - 郑直："什么破密码，故弄玄虚！" 后退两步，准备暴力破解
   - 一脚踹上去，锁没开，门没动，郑直退了一步："哦？挺结实"
   - 第二脚，加上全身力量，直接把锁连门框架一起砸下来了（物理破解成功，系统提示：获得技巧值15点——高效物理解谜判定）
   - 进门搜索：郑直错误推理认为密码在床底下，翻了半天什么都没有
   - 直觉触发：郑直突然觉得"镜子不对劲"，回头检查门框上方的小镜子
   - 发现镜子框角落刻着数字"3"，这是第一个密码数字

5. **线索收集**
   - 依此类推，郑直在另外三面大镜子框上都发现了数字：3、7、1、4
   - 尝试排列密码，两次错误后，郑直不耐烦了："排列什么排列，直接砸！"
   - 第二扇门锁比较结实，郑直花了点时间，硬是用肩撞把锁撞开了（又获得技巧值10点）
   - 在房间里找到**逃生通道门钥匙**，还有一张泛黄的便签："影子怕光，找到光源就能驱散它"

6. **向天台转移**
   - 拿到钥匙后，黑影已经追到房间门口
   - 郑直转身往走廊尽头逃生通道跑去，黑影在身后紧追不舍
   - 体能值还剩35点，到达逃生通道门口，用钥匙开门
   - 门打开，是向上的楼梯，章节结束

## 第三章：天台光源与结算奖励

### 章节功能
- 最终战斗/解决
- 完成教程
- 奖励结算与系统解锁

### 内容大纲

1. **天台探索**
   - 郑直爬上楼梯，到达旅馆天台
   - 天台上布满灰尘，角落有一个大型老旧探照灯，对着楼梯口方向
   - 郑直又开始错误推理："密码一定是探照灯的出厂编号！我就说那四个数字不对..." 开始找铭牌
   - 黑影已经顺着楼梯爬上天台，整个天台边缘都被黑影笼罩
   - 直觉强烈预警："别找密码了！快开探照灯！"

2. **最终解决**
   - 郑直虽然推理错了，但信任直觉，立刻冲向探照灯
   - 探照灯的电源开关已经锈死，按不动
   - 郑直抓住开关把手，一声大喝，发力直接把开关整个掰碎了（物理又赢了）
   - 探照灯突然亮起，耀眼的白光直射而来
   - 强光扫过，黑影发出尖啸，开始快速消融，几秒钟后彻底消失

3. **剧本完成**
   - 系统提示：【剧本已完成，传送返回登陆空间】
   - 白光一闪，郑直回到自己的登陆空间

4. **奖励结算**（严格遵循系统规范）
   ```
【剧本已完成，正在结算奖励。】
【获得经验值：80，游戏币：800】
【获得物品/装备：无】
【完成/接受任务：0/0】
【特殊、隐藏任务完成：0，破解世界观：无】
【惊吓值激增：0次，最高惊吓值：5%，平均惊吓值：2%】
【您的恐惧评级为：浑身是胆，获得一项额外奖励，请稍后选取。】
【获得技巧值：45（基础解谜奖励20+物理解谜额外奖励25）】
【技巧值加成经验：45，游戏币：450】
【剧本通关奖励：新手行囊*1。】
【结算已完成，请继续。】
   ```

5. **额外奖励抽取**
   - 三个奖励柱，郑直随便选了中间那个
   - 玻璃柱亮起，里面出现一块石头
   - 物品信息：
     ```yaml
名称: 石头
类型: 武器
品质: 垃圾
攻击力: 微弱
属性: 无
特效: 无
是否可带出该剧本: 是
备注: 随处可见、形状不规则的石块，有时会被拾起来当武器使用...
     ```
   - 郑直愣了两秒，然后哈哈大笑："好！正好我下本书里那个镜子反派就叫'黑影'，这块石头带回家当镇纸，镇一镇这邪气！完美！"
   - 延续原作幽默反转，符合郑直性格

6. **系统解锁**
   - 新手教程完成，解锁系统功能：
     - 行囊系统开启（初始容量10格）
     - 专精系统解锁：
       - 格斗专精：D级（成功使用暴力破解多次，自动解锁），成功率60%
       - 侦查专精：F级（多次触发直觉感知，自动解锁），附带直觉特化效果
       - 通用专精：F级（教程完成自动解锁）
     - 获得初始称号【直觉莽夫】：
       > 效果：物理破坏场景物品时，体能消耗降低30%
       > 符合郑直风格，完美契合角色设定

7. **结尾**
   - 郑直检查完属性和奖励，握紧拳头："不错不错，这个游戏真有意思， enough material for my next novel！"（偶尔蹦英文，展示他虽然一根筋但还是努力学习写作）
   - 郑直选择单人生存模式，准备开始下一个剧本，故事结束本章

## 创作特色总结

1. **符合原作风格**：保持《惊悚乐园》新手教程的结构、机制教学顺序和系统提示风格
2. **完全不同剧情**：原创场景（古旧旅馆八楼镜影），原创怪物（镜子黑影），原创解谜流程，不重复原作血尸追逐
3. **突出角色特点**：全程体现郑直"错误推理→直觉指引→物理破解"的特色，喜剧效果拉满
4. **严格遵循设定**：所有系统机制、专精解锁、称号效果都符合《惊悚乐园》世界观设定
5. **保持喜剧平衡**：恐怖场景后及时用郑直的错误推理和物理破解制造喜剧缓解，符合郑直"重度喜剧担当"定位
