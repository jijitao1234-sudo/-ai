# 装备系统规范

## 一、装备品质分级体系

### 1.1 品质等级定义
装备品质分为六级，从低到高依次为：

| 品质等级 | 描述 | 示例 | 属性特征 |
|---------|------|------|----------|
| **垃圾** | 基本无用的物品，攻击力微弱 | 石头 | 无属性，无特效 |
| **破败** | 严重损坏的物品，性能低下 | （待补充） | 可能有轻微负面效果 |
| **普通** | 标准功能物品，无特殊效果 | 生锈的铁钥匙 | 基本功能，无特效 |
| **精良** | 优质装备，有明显优势 | 血尸必须死 | 至少含一种属性或特效 |
| **完美** | 稀有装备，性能卓越 | （待补充） | 多种属性或强力特效 |
| **传说** | 史诗级装备，极为罕见 | （待补充） | 独特特效，可能改变游戏玩法 |

### 1.2 品质获取概率
- **新手教程**：可能获得精良品质装备作为奖励
- **普通剧本**：主要产出普通、精良品质
- **噩梦剧本**：更高概率获得精良、完美品质
- **特殊活动**：可能产出传说品质

## 二、物品属性结构

### 2.1 通用物品属性字段
所有物品都包含以下基本属性字段：

```yaml
名称: [物品名称]
类型: [消耗品/武器/防具/任务物品等]
品质: [垃圾/破败/普通/精良/完美/传说]
功能: [物品的主要用途描述]
是否可带出该剧本: [是/否]
备注: [额外说明、背景故事或提示]
```

### 2.2 武器专用属性字段
武器类物品额外包含以下字段：

```yaml
攻击力: [微弱/较弱/一般/较强/强/极强]
属性: [火焰/冰霜/雷电/神圣/暗影/无]
特效: [特殊效果描述，如"攻击血尸时可将其溶解"]
```

### 2.3 属性字段详解

#### 2.3.1 攻击力分级标准
- **微弱**：基本无威胁，如石块投掷
- **较弱**：轻微伤害，如小刀划伤
- **一般**：标准伤害，如普通刀具
- **较强**：显著伤害，如优质武器
- **强**：高伤害，如重型武器
- **极强**：致命伤害，如传奇武器

#### 2.3.2 属性类型
- **火焰**：对惧火生物额外伤害，可能点燃目标
- **冰霜**：减缓目标速度，对火系生物克制
- **雷电**：麻痹效果，对机械类敌人有效
- **神圣**：对亡灵、恶魔类敌人特效
- **暗影**：潜行加成，对圣洁生物克制
- **无**：无特殊属性

## 三、装备获取机制

### 3.1 搜索获取
- **环境搜索**：在剧本场景中主动寻找
  - 墙壁后隐藏空间
  - 家具内部
  - 尸体身上
  - 特殊容器内
- **搜索技巧**：侦查专精影响搜索效率和发现隐藏物品的概率

### 3.2 任务奖励
- **主线任务**：通关剧本基础奖励
- **支线任务**：额外装备奖励
- **隐藏任务**：稀有装备奖励
- **特殊成就**：如"浑身是胆"评级额外奖励

### 3.3 制造与兑换
- **惊吓盒子**：使用技巧值兑换剧本限定物品
- **套牌系统**：拼图牌兑换保底精良级装备
- **交易所**：内测后期开放玩家交易（当前屏蔽）

## 四、装备使用规则

### 4.1 装备栏系统
- **无部位限制**：玩家可同时装备多件武器和防具
- **装备数量**：仅受行囊容量和负重概念限制
- **服装系统**：与角色形象绑定，不属于装备，仅可在登陆空间更改

### 4.2 行囊系统
- **初始容量**：10件物品
- **存放规则**：
  - 必须能塞入背包口
  - 活物需获得控制权才可存放
  - 玩家无法进入行囊
- **容量扩展**：通过特殊物品或等级提升增加

### 4.3 装备绑定规则
- **剧本绑定**：部分物品"不可带出该剧本"
- **角色绑定**：技能卡装备后与角色绑定
- **交易限制**：内测阶段禁止虚拟物品交易

## 五、特殊装备系统

### 5.1 套牌系统
- **拼图牌来源**：可带出剧本的剧情物品转化
- **套牌系列**：十二生肖、西游角色、星座等主题
- **兑换奖励**：保底精良级，概率完美级装备

### 5.2 专属装备
- **称号关联**：某些称号解锁专属装备使用权限
- **专精需求**：高级装备需要对应专精等级
- **剧情获取**：特定剧本通关奖励专属装备

## 六、平衡性与成长曲线

### 6.1 新手期装备（1-5级）
- **主要来源**：新手教程、训练模式
- **品质范围**：垃圾、普通为主，小概率精良
- **设计目标**：让玩家熟悉装备系统基础

### 6.2 成长期装备（6-15级）
- **主要来源**：生存模式、支线任务
- **品质范围**：普通、精良为主，开始出现完美
- **设计目标**：支持玩家构建战斗风格

### 6.3 高级期装备（16-20级）
- **主要来源**：噩梦模式、套牌兑换、隐藏任务
- **品质范围**：精良、完美为主，传说稀有
- **设计目标**：提供end-game内容和收集要素

## 七、设计原则与注意事项

### 7.1 核心设计原则
1. **无职业限制**：装备系统支持多种build方向
2. **品质阶梯**：明确的成长路径和追求目标
3. **获取多样性**：多种途径获取装备，避免单一化
4. **平衡性**：避免某件装备过于破坏游戏平衡

### 7.2 剧本内装备设计
1. **环境契合**：装备应与剧本主题和场景协调
2. **解谜关联**：部分装备作为解谜关键道具
3. **剧情融合**：装备备注可包含背景故事或提示
4. **难度适配**：装备强度匹配剧本难度等级

### 7.3 玩家体验考量
1. **新手引导**：教程中逐步介绍装备系统
2. **信息透明**：属性字段清晰明确
3. **反馈及时**：获得装备时有明确提示和说明
4. **收藏价值**：稀有装备具有展示和收集价值

## 八、示例装备分析

### 8.1 垃圾品质示例：石头
```yaml
名称: 石头
类型: 武器
品质: 垃圾
攻击力: 微弱
属性: 无
特效: 无
是否可带出该剧本: 是
备注: 随处可见、形状不规则的石块，有时会被拾起来当武器使用，虽然可以自由带出或带入任何剧本，但人们总是用完就扔，根本不会装进行囊或者一直拿着。
```

### 8.2 普通品质示例：生锈的铁钥匙
```yaml
名称: 生锈的铁钥匙
类型: 消耗品
品质: 普通
功能: 打开门锁
是否可带出该剧本: 否
备注: 我想你知道该怎么做。
```

### 8.3 精良品质示例：血尸必须死
```yaml
名称: 血尸必须死
类型: 武器
品质: 精良
攻击力: 较强
属性: 无
特效: 攻击血尸时可将其溶解
是否可带出该剧本: 否
备注: 这把剑是传奇矮人工匠"奥尔·全得死"的早期作品，一名狡猾的哥布林商人用几瓶被称为"二锅头"的饮料就从奥尔那里收购了此剑，半个月后，奥尔制造了"哥布林必须死"。
```
