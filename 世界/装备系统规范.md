# 装备系统规范

## 一、装备品质分级体系

### 1.1 品质等级定义
装备品质分为六级，从低到高依次为：

| 品质等级 | 描述 | 示例 | 属性特征 |
|---------|------|------|----------|
| **垃圾** | 基本无用的物品，攻击力微弱 | 石头 | 无属性，无特效 |
| **破败** | 严重损坏的物品，性能低下 | 磨损的小刀 | 可能有轻微负面效果 |
| **普通** | 标准功能物品，无特殊效果 | 生锈的铁钥匙 | 基本功能，无特效 |
| **精良** | 优质装备，有明显优势 | 血尸必须死 | 至少含一种属性或特效 |
| **完美** | 稀有装备，性能卓越 | 鼠槌 | 多种属性或强力特效 |
| **传说** | 史诗级装备，极为罕见 | 红色战斗伞 | 独特特效，可能改变游戏玩法 |

### 1.2 品质获取概率
- **新手教程**：可能获得精良品质装备作为奖励
- **普通剧本**：主要产出普通、精良品质
- **噩梦剧本**：更高概率获得精良、完美品质
- **特殊活动**：可能产出传说品质

## 二、物品属性结构

### 2.1 通用物品属性字段
所有物品都包含以下基本属性字段：

```yaml
名称: [物品名称]
类型: [消耗品/武器/防具/工具/任务物品等]
品质: [垃圾/破败/普通/精良/完美/传说]
功能: [物品的主要用途描述]
是否可带出该剧本: [是/否]
备注: [额外说明、背景故事或提示]
```

### 2.4 工具专用属性字段
工具类物品额外包含以下字段（根据工具类型可能有所不同）：

```yaml
耐久度: [当前耐久度/最大耐久度]
特殊功能: [如"照明"、"开锁"等]
```

### 2.2 武器专用属性字段
武器类物品额外包含以下字段：

```yaml
攻击力: [微弱/较弱/一般/较强/强/极强]
属性: [火焰/冰霜/雷电/神圣/暗影/无]
特效: [特殊效果描述，如"攻击血尸时可将其溶解"]
```

### 2.3 属性字段详解

#### 2.3.1 攻击力分级标准
- **微弱**：基本无威胁，如石块投掷
- **较弱**：轻微伤害，如小刀划伤
- **一般**：标准伤害，如普通刀具
- **较强**：显著伤害，如优质武器
- **强**：高伤害，如重型武器
- **极强**：致命伤害，如传奇武器

#### 2.3.2 属性类型
- **火焰**：对惧火生物额外伤害，可能点燃目标
- **冰霜**：减缓目标速度，对火系生物克制
- **雷电**：麻痹效果，对机械类敌人有效
- **神圣**：对亡灵、恶魔类敌人特效
- **暗影**：潜行加成，对圣洁生物克制
- **无**：无特殊属性

## 三、装备获取机制

### 3.1 搜索获取
- **环境搜索**：在剧本场景中主动寻找
  - 墙壁后隐藏空间
  - 家具内部
  - 尸体身上
  - 特殊容器内
- **搜索技巧**：侦查专精影响搜索效率和发现隐藏物品的概率

### 3.2 任务奖励
- **主线任务**：通关剧本基础奖励
- **支线任务**：额外装备奖励
- **隐藏任务**：稀有装备奖励
- **特殊成就**：如"浑身是胆"评级额外奖励

### 3.3 制造与兑换
- **惊吓盒子**：使用技巧值兑换剧本限定物品
- **套牌系统**：拼图牌兑换保底精良级装备
- **交易所**：内测后期开放玩家交易（当前屏蔽）

## 四、装备使用规则

### 4.1 装备栏系统
- **无部位限制**：玩家可同时装备多件武器和防具
- **装备数量**：仅受行囊容量和负重概念限制
- **服装系统**：与角色形象绑定，不属于装备，仅可在登陆空间更改

### 4.2 行囊系统
- **初始容量**：10件物品
- **存放规则**：
  - 必须能塞入背包口
  - 活物需获得控制权才可存放
  - 玩家无法进入行囊
- **容量扩展**：通过特殊物品或等级提升增加

### 4.3 装备绑定规则
- **剧本绑定**：部分物品"不可带出该剧本"
- **角色绑定**：技能卡装备后与角色绑定
- **交易限制**：内测阶段禁止虚拟物品交易

## 五、特殊装备系统

### 5.1 套牌系统（简要说明）
> *详细说明请参见第十章【套牌系统详细说明】*
- **拼图牌来源**：可带出剧本的剧情物品转化
- **套牌系列**：十二生肖、西游角色、星座等主题
- **兑换奖励**：保底精良级装备，概率完美级装备
- **系统定位**：为玩家提供获取高级装备的补充途径

### 5.2 专属装备
- **称号关联**：某些称号解锁专属装备使用权限
- **专精需求**：高级装备需要对应专精等级
- **剧情获取**：特定剧本通关奖励专属装备

### 5.3 剧情物品系统
- **类型定义**：推动剧情发展的关键物品，如钥匙、道具等
- **属性规范**：通常包含"功能"字段说明其剧情作用
- **带出限制**：多数剧情物品不可带出剧本
- **特殊机制**：部分剧情物品可转化为拼图牌

### 5.4 装备与技能的互动机制
- **临时提升品质**：如【草率的维修】技能可使破败品质的机械造物暂时提升为普通品质
- **效果增强**：特定装备可增强对应专精技能的效果
- **使用限制**：部分技能需要特定装备才能发挥最大效果

## 六、平衡性与成长曲线

### 6.1 新手期装备（1-5级）
- **主要来源**：新手教程、训练模式
- **品质范围**：垃圾、普通为主，小概率精良
- **设计目标**：让玩家熟悉装备系统基础

### 6.2 成长期装备（6-15级）
- **主要来源**：生存模式、支线任务
- **品质范围**：普通、精良为主，开始出现完美
- **设计目标**：支持玩家构建战斗风格

### 6.3 高级期装备（16-20级）
- **主要来源**：噩梦模式、套牌兑换、隐藏任务
- **品质范围**：精良、完美为主，传说稀有
- **设计目标**：提供end-game内容和收集要素

### 6.4 非显性属性影响
- **现实能力映射**：玩家现实中的身体素质会影响游戏中的体能消耗（如跑步消耗）
- **技能熟练度**：现实中具备相关技能的玩家在游戏中使用对应装备时会有轻微优势
- **长期影响**：这种差异在低等级时较明显，高等级时逐渐被游戏属性覆盖

## 七、设计原则与注意事项

### 7.1 核心设计原则
1. **无职业限制**：装备系统支持多种build方向
2. **品质阶梯**：明确的成长路径和追求目标
3. **获取多样性**：多种途径获取装备，避免单一化
4. **平衡性**：避免某件装备过于破坏游戏平衡

### 7.2 剧本内装备设计
1. **环境契合**：装备应与剧本主题和场景协调
2. **解谜关联**：部分装备作为解谜关键道具
3. **剧情融合**：装备备注可包含背景故事或提示
4. **难度适配**：装备强度匹配剧本难度等级

### 7.3 玩家体验考量
1. **新手引导**：教程中逐步介绍装备系统
2. **信息透明**：属性字段清晰明确
3. **反馈及时**：获得装备时有明确提示和说明
4. **收藏价值**：稀有装备具有展示和收集价值

## 九、专精需求与系统关联

### 9.1 专精需求说明
部分高级装备需要玩家具备相应的专精等级才能使用：

```yaml
专精需求: [所需专精类型及最低等级]
```

**专精等级对应关系**：
- **无需求**：垃圾、破败、普通品质装备
- **F-E级**：部分精良品质装备
- **D-C级**：多数精良品质装备，部分完美品质装备
- **B-A级**：多数完美品质装备，部分传说品质装备
- **S级**：顶级传说品质装备

**示例**：
- 通用专精D：部分精良级装备需求
- 格斗专精B：高级近战武器需求
- 射击专精A：顶级远程武器需求

### 9.2 与技能系统的关联
- **专精一致性**：装备的专精需求与技能系统规范的专精等级体系保持一致
- **效果加成**：特定装备可以增强对应专精技能的效果
- **使用限制**：高专精需求装备需要相应专精等级才能发挥全部效果

### 9.3 与拼图牌系统的关联
- **兑换机制**：套牌系统兑换的装备品质保底为精良，概率出现完美
- **获取途径**：拼图牌是获取高级装备的重要补充途径
- **品质对应**：拼图牌兑换装备的品质与装备系统规范的品质分级对应

## 十、套牌系统详细说明

### 10.1 拼图牌获取
- **来源**：可带出剧本的剧情物品转化
- **转化规则**：剧情物品进入登陆空间后自动转化为拼图牌
- **随机性**：同一剧情物品可能转化为不同主题的拼图牌

### 10.2 套牌系列
- **主题类型**：十二生肖、西游角色、星座、T-800等
- **组合规则**：系统判定一组牌能构成"一套"概念即可
- **灵活性**：同一张牌可加入多个不同系列

### 10.3 兑换奖励
- **品质保底**：精良级装备
- **概率分布**：精良80%，完美20%
- **兑换条件**：必须通关剧本，死亡无法获得拼图牌
