# 世界观核心设定

## 一、游戏核心设定（深化补充）

### 1.1 《惊悚乐园》游戏基础设定
- **背景**：原本由梦公司研发的神经连接型虚拟游戏《惊悚乐园》关服十五年后，突然重新开服，目的不明。但由于其都市传说一般离奇的运营经历，从而吸引了一大批好奇的玩家前来游玩。
- **游戏载体**：
  - **游戏版本**：NL2065 标准单人游戏舱，支持第四代光脑技术，提供足以乱真的五感体验（玩家吐槽NL2065与前代NL2055之间除了数字根本没有区别）
- **游戏登入模式**：
  - **非睡眠模式**：游戏时间与现实时间比 2:1，适合短时间游戏
  - **睡眠模式**：时间比 10:1（梦中无时间），适合长时间游戏，两种模式服务器独立、无法互通
- **技术基础**：第四代光脑技术支持神经连接，玩家可获得足以乱真的五感体验（包括视觉、听觉、嗅觉、味觉、触觉），但游戏画面依然局限于CG影像，无法达到真人实景拍摄效果。游戏舱实时监控玩家心跳、脉搏、血压、脑神经反应，测算惊吓值，超过临界点强制断开连接。

### 1.2 《惊悚乐园》游戏模式
  - **新手教程**：随机生成剧本，限完成一次。玩家因惊吓值过高、主动断开连接、离开游戏舱等原因中断教程时，下次进入游戏将无法继续原先的剧本，系统会生成新的教程。教程结果不影响角色初始属性，仅奖励不同。
    *示例*：封不觉的新手教程为血尸追逐战（寻找钥匙→使用【血尸必须死】击杀血尸）
  - **训练模式**：含单人 / 多人两种，为新手设计，五级后不可见，仅奖励经验值，无技巧值和额外奖励。玩家到达五级后该模式选项消失。
    *示例*：封不觉与王叹之的多人训练模式为医院超能力儿童剧本（解谜获得【爆炸神拳】→利用阳光弱点击杀BOSS）
  - **生存模式**：核心玩法，分单人 / 团队（2-6 人随机匹配），提供剧本简介、支线 / 隐藏任务及特殊世界观，奖励含经验值、游戏币、技巧值、技能卡 / 装备，通关可获额外奖励。
    *示例*：封不觉的单人生存模式为竖锯风格密室（重量谜题→寒冷房间解密→道德选择）
  - **生存模式(噩梦)**：比生存模式更加危险、恐怖，分单人 / 团队（2-6 人随机匹配）提供剧本简介、支线 / 隐藏任务及特殊世界观，奖励含经验值、游戏币、技巧值、技能卡 / 装备，通关可获更多额外奖励。
  - **杀戮游戏模式**：支持玩家对抗


### 1.3 核心机制
- **角色属性**：
**生存值**：以百分比显示，具体数值不可见。生存值为0%时，角色被视为已死亡。受攻击、环境伤害等影响。当前生存值：100%，异常状态：无。
*示例*：封不觉在新手教程中肘击墙壁，生存值从100%降至98%
**体能值**：具体数值可见。奔跑、长时间行走、搬运重物、格斗、使用技能等行为都将减少该数值。可通过休息或物品回复。初始100，每级递增100。
*示例*：封不觉在新手教程中跑步、踹门、砸墙、登坡后，体能值从100降至24/100
**惊吓值**：以百分比显示，无具体数值。惊吓值高于100%并超过三秒，玩家与游戏的连接将被强制断开，角色被视为已死亡。通过光脑和游戏舱功能，实现对玩家心跳、脉搏、血压、脑神经反应等即时监控，以此测算恐惧的程度。恐惧评级分“浑身是胆”“勇气可嘉”“惊慌失措”“胆颤心惊”“魂不附体”五级，影响额外奖励。
*示例*：封不觉因脑部疾病惊吓值始终为0%，王叹之在正常游戏中心跳加速时惊吓值会瞬间上升
**技巧值**：核心货币之一，具体数值可见。通过解谜、高效战斗、破解世界观等提升游戏效率的行为获取，凡是提升游戏效率的行为皆会奖励技巧值。不可交易，仅可在“惊吓盒子”（系统特殊商店）兑换游戏币（1:10比例）或剧本限定物品（属性会调整）。
*示例*：封不觉在新手教程中通过解谜找到钥匙获得30点技巧值
- **专精系统**：
共六种：格斗、射击、器械、侦查、医疗、通用，等级从 N/A（无法使用该系技能）到 F 及以上，F 级可使用对应技能，发动成功率 20%，等级提升后成功率和效果增强。
*开启条件*：
- **格斗**：通过战斗行为解锁（如王叹之在教程中击杀怪物后开启）
- **器械**：通过摆弄机械物品解锁（如封不觉在剧本中操作walkman后开启）
- **侦查**：通过解谜、观察细节解锁
- **医疗**：通过使用医疗物品或治疗行为解锁
- **射击**：通过使用远程武器解锁
- **通用**：教程结束后自动开启，所有玩家初始拥有F级
无职业限制，玩家可自由发展多专精，形成独特战斗/解谜风格。
- **装备与技能**：
**装备品质**：分垃圾、破败、普通、精良、完美、传说六级。
- **垃圾**：如【石头】，攻击力微弱，无属性特效，可自由带出/带入剧本但无人保留
- **破败**：如【水果刀】，攻击力较弱，无属性特效，比垃圾略好
- **普通**：如【生锈的铁钥匙】，基本功能物品，品质正常
- **精良**：如【血尸必须死】，攻击力较强，至少含一种属性或特效（特效：攻击血尸时可将其溶解）
精良及以上装备至少含一种属性或特效，获取方式以“搜索”为主（剧本场景中寻找），内测后期可通过交易所、套牌系统兑换。
**物品系统**：
- **物品属性结构**：名称、类型、品质、功能、是否可带出该剧本、备注
- **武器属性结构**：名称、类型、品质、攻击力、属性、特效、是否可带出该剧本、备注
- **攻击力分级**：微弱、较弱、一般、较强、强、极强
- **物品获取**：剧本中搜索获得，部分为任务奖励，无“掉宝”概念（怪物死亡不会爆装备）
*示例物品*：
- 【一次性注射器】：消耗品，品质普通，功能：抽取或注射液体
- 【不明身份者的病历】：剧情相关，品质普通，功能未知，不可带出剧本
- 【人脸素描*6】：剧情相关，品质普通，可拆分或堆叠

**技能卡**：
- **类型**：分主动（永久掌握、限时拥有、按次数消耗）和被动（永久掌握、限时拥有）
- **学习条件**：需满足对应专精等级才能学习
- **绑定规则**：装备后与角色绑定，技能栏上限 12 格，仅剧本开始前可调整
- **带入规则**：技能卡作为物品时只能带出剧本，不能带入（防止备用卡滥用）
*示例*：【爆炸神拳】- 主动技能，按次数消耗（2次），技能类别：格斗，效果：击中目标后产生爆炸造成火属性伤害，消耗：体能值50，学习条件：格斗专精F
**套牌系统**：可带出剧本的剧情物品会转化为“拼图牌”，任意凑齐系统判定的“系列套牌”（如十二生肖、西游相关、各种概念组合），可兑换保底精良级、概率完美级的装备，为无装备玩家提供成长途径。
*示例*：【昏睡的藏猕猴】（剧情物品，可带出剧本）→ 转化为【拼图牌：猴】，可与其他拼图牌组合成系列
- **社交与规则**：
**社交系统**：
- **功能分类**：【最近一起游戏的玩家】【好友】【黑名单】
- **操作限制**：仅登陆空间可操作好友申请/黑名单，剧本中无法进行
- **沟通方式**：
  - 好友：可通过登陆空间屏幕直接通讯（无视频）
  - 非好友：仅能通过邮件沟通（24小时限3封，每封≤1000字）
- **防骚扰机制**：敏感词汇消音处理，性骚扰/歧视行为将被系统限制，反复尝试强制断线并加入黑名单，严重者永久封停账号并移交公安部门
**组队机制**：
- 队伍人数：2-6人随机匹配
- 队长权限：选择游戏模式
- 经验分配：多人模式幸存者经验一致（坑队友会扣经验）
- 物品分配：谁发现归谁，无组队关系玩家间很少分享

### 1.3 世界维度与剧情核心
- **剧本生成逻辑**：剧本由系统基于庞大数据库和玩家记忆碎片随机生成，场景涵盖医院、鬼屋、城市、地窖、走廊、山坡等恐怖主题，融合解谜、战斗、生存元素，难度匹配玩家等级与团队实力（多人模式有加成）。
- **新手教程剧本特点**：包含基础解谜（如寻找钥匙）、基础战斗（使用特定武器对抗怪物）、环境互动（破坏墙壁获取物品）等元素，引导玩家熟悉游戏机制。
- **世界观破解**：玩家解读出剧本背后的设定（如时间循环、诅咒来源、超能力起源等）可获得大量技巧值奖励
- **剧本类型示例**：
  1. **超自然力量**：如医院超能力儿童（意念移物、人格变异、精神污染）
  2. **心理恐怖**：如竖锯风格密室（道德选择、自我救赎、时间压力）
  3. **传统恐怖**：如血尸追逐战（怪物追杀、环境解谜）
  4. **时空循环都市**：如诡影迷城（黑暗死城、恶魔之门、时间循环真相）
  5. **经典文学改编恐怖**：如山池鬼屋厄舍府（古老大宅诅咒、空间幻觉、文学彩蛋）
  6. **暴风雪山庄推理**：如特别篇侦探剧本（家族秘密、密室杀人、多重反转）
  7. **生化丧尸危机**：如努卡市病毒事件（全城感染、GM卧底、衍生者伏笔）
  8. **IP跨界搞笑融合**：如日和宇宙特别篇（动物拟人、meta叙事、无厘头幽默）
  9. **日式校园恐怖**：如校园七不思议（七种灵异传说、强制分离规则、双人合作）
  10. **荒岛追捕逃生**：如猎人岛剧本（名著改编、狩猎游戏、智斗反杀）
  11. **玩家对抗PVP**：如杀戮游戏模式（1V1随机匹配、隐藏任务、势力博弈）
- **难度控制**：系统不会生成玩家依靠初始状态即可立即通关的剧本，必死局面在普通难度中不存在

## 二、成长体系与核心规则

### 2.1  等级与称号
- **等级上限**：内测封顶 20 级，升级经验前期按每级递增 100 设定（1-10级），11级后经验需求大幅提升（11级需11000经验）。
*示例*：封不觉从1级升到2级需100经验，2级升到3级需200经验，4级升到5级需400经验
- **称号系统**：十级解锁，根据玩家表现实时更新，赋予特殊能力（如龙傲 F 的【勇猛的冲锋者】可发动【闪电冲撞】，封不觉的【冷血爆头狂】可触发头部攻击眩晕特效），能力类型含主动、被动，不占用技能栏，是角色个性化的核心体现。

### 2.2 核心规则底线
- **无职业限制**：玩家可自由搭配装备、技能、专精，形成独特战斗 / 解谜风格（如封不觉的 “解谜 + 爆头”，似雨若离的 “近战爆发”）。
- **非显性属性影响**：现实中的身体素质、技能基础（如是否会用枪）会轻微影响游戏内表现（如体能消耗、射击准度），但不影响核心平衡。
- **奖励机制**：
  - **经验值**：分配公平（多人模式幸存者经验一致，坑队友会扣经验）
  - **技巧值**：奖励倾向高效行为（解谜一次性获取多，战斗可累积），通过高收益低损失击杀、连杀、特殊击杀等方式获取
  - **惊吓值**：越低奖励越丰厚，恐惧评级影响额外奖励
  - **结算规则**：品质为"普通"以下的消耗品和"垃圾"装备带出剧本时不在结算清单显示（防止垃圾物品刷屏）
*示例*：封不觉新手教程结算：经验值70+技巧值加成30=100，游戏币700+加成300=1000，恐惧评级"浑身是胆"获得额外奖励

### 2.3 关键势力
- **系统方**：惊悚乐园游戏运营及其管理AI（中立但不可预测）
- **玩家**：乐子人，网络考古者，靠游戏爱好者。


### 2.4 核心悬念
- **长期悬念（全书级）**：
  - 游戏重新开服的真实目的是什么？
  - 系统背后是否有更高维度的操控者？
  - 主角的脑部疾病与游戏系统有什么关联？
  - 现实与虚拟的边界在哪里？
- **中期悬念（副本级）**：
  - 每个剧本隐藏的世界观真相是什么？
  - 剧情物品和拼图牌暗示了什么？
  - 特殊NPC的真实身份是什么？
- **短期悬念（章节级）**：
  - 当前谜题的解答是什么？
  - 下一个房间/区域有什么危险？
  - 角色能否成功逃脱当前困境？

## 三、叙事结构与剧本设计

### 3.1 整体叙事结构（三层嵌套）
《惊悚乐园》采用多层嵌套叙事结构，三个维度相互交织推进剧情：
- **现实层**：主角封不觉的现实生活、疾病背景、人际关系，平衡游戏剧情，提供人物成长根基
- **游戏层**：惊悚乐园游戏系统、副本推进、规则交互，是故事的主要发生场景
- **Meta层**：系统背后的真相、游戏与现实的边界模糊、存在本质探讨，是核心主题承载

### 3.2 宏观卷章结构
全书按成长阶段划分为四卷：
- **第一卷（新手期）**：1-100章，熟悉系统、获取基础能力、建立初步社交
- **第二卷（成长期）**：101-500章，能力提升、团队建立、接触更深层次剧情
- **第三卷（高手期）**：501-1000章，高难度副本、势力冲突、主线加速推进
- **第四卷（巅峰期）**：1001-1518章，真相揭露、最终对决、主题升华

### 3.3 标准剧本结构（3-5章）
每个常规独立副本遵循模块化设计，节奏清晰：
1. **第1章：引入**
   - 副本背景介绍、系统提示
   - 任务目标明确，给出主线/隐藏任务提示
   - 展示角色状态、能力限制和资源情况
2. **第2-3章：发展**
   - 环境探索、线索收集
   - 冲突与挑战，解决谜题
   - 团队互动、策略讨论
3. **第4-5章：高潮与解决**
   - 最终挑战（BOSS战/最终谜题）
   - 反转揭示隐藏真相
   - 奖励结算、能力提升

### 3.4 游戏机制渐进解锁
按新手教程递进顺序，分阶段解锁核心机制，避免信息过载：

| 机制 | 解锁剧本 | 教学方式 |
|------|----------|----------|
| 生存值/体能值/惊吓值 | 新手教程（剧本1） | 系统提示+视觉展示，实战应用 |
| 技巧值 | 新手教程（剧本1） | 解谜获得奖励时提示 |
| 物品系统 | 新手教程（剧本1） | 获得物品时逐步解锁菜单 |
| 行囊系统 | 新手教程（剧本1） | 教程完成结算后解锁 |
| 专精系统 | 新手教程（剧本1） | 首次升级后解锁 |
| 多人游戏规则 | 多人训练模式（剧本2） | 进入模式前系统提示 |
| 社交系统 | 多人训练模式（剧本2） | 结算后详细介绍功能 |
| 拼图牌/套牌系统 | 单人生存模式（剧本3） | 获得可带出剧情物品后揭示 |
| 称号系统 | 达到十级后 | 等级达标自动解锁 |

### 3.5 节奏控制规律
- **快慢交替循环**：紧张副本 → 轻松日常 → 新副本引入，每3-5章完成一次完整循环
- **情绪转换设计**：恐怖 → 幽默 → 智斗 → 反转 → 解决，避免单一情绪疲劳
- **悬念层次设置**：章末留短期钩子，副本藏中期谜团，全书铺长期悬念

## 四、核心主题（升华提炼）
> 待后续剧情推进后逐步填充，可围绕以下方向深化：
- 恐惧与人性的探讨
- 现实与虚拟的边界思考
- 理性与疯狂的界限
- 存在意义的追问

## 使用说明

1. **创作参考**：此设定为创作者提供完整世界观框架
2. **灵活调整**：可根据具体剧情需要调整细节
3. **渐进揭示**：建议在故事中逐步揭示世界观，保持悬念
4. **角色互动**：不同角色对此世界观应有不同认知和态度
