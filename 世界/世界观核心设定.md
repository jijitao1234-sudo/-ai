# 世界观核心设定

## 一、游戏核心设定（深化补充）

### 1.1 《惊悚乐园》游戏基础设定
- **背景**：原本由梦公司研发的神经连接型虚拟游戏《惊悚乐园》关服十年后，突然重新开服，目的不明。但由于其都市传说一般离奇的运营经历，从而吸引了一大批好奇的玩家前来游玩。
- **游戏载体**：核心载体为 NL2065 标准单人游戏舱（很玩家吐槽NL2065与前代NL2055之间除了数字根本没有区别）。内测阶段使用NL2055标准单人游戏舱，支持第四代光脑技术，提供足以乱真的五感体验。
- **游戏登入模式**：非睡眠模式（游戏时间与现实时间比 2:1）和睡眠模式（时间比 10:1，建议单次不超过 4 小时），两种模式服务器独立、无法互通。
- **技术基础**：第四代光脑技术支持神经连接，玩家可获得足以乱真的五感体验，但游戏画面依然局限于CG影像，无法达到真人实景拍摄效果。

### 1.2 《惊悚乐园》游戏模式
  - **新手教程**：随机生成剧本，限完成一次。玩家因惊吓值过高、主动断开连接、离开游戏舱等原因中断教程时，下次进入游戏将无法继续原先的剧本，系统会生成新的教程。教程结果不影响角色初始属性，仅奖励不同。
  - **训练模式**：含单人 / 多人两种，为新手设计，五级后不可见，仅奖励经验值，无技巧值和额外奖励。
  - **生存模式**：核心玩法，分单人 / 团队（2-6 人随机匹配），提供剧本简介、支线 / 隐藏任务及特殊世界观，奖励含经验值、游戏币、技巧值、技能卡 / 装备，通关可获额外奖励。
  - **生存模式(噩梦)**比生存模式更加危险，恐怖，分单人 / 团队（2-6 人随机匹配）提供剧本简介、支线 / 隐藏任务及特殊世界观，奖励含经验值、游戏币、技巧值、技能卡 / 装备，通关可获更多额外奖励。
  - **杀戮游戏模式**：支持玩家对抗


### 1.3 核心机制
- **角色属性**：
**生存值**：以百分比显示，具体数值不可见。生存值为0%时，角色被视为已死亡。受攻击、环境伤害等影响。当前生存值：100%，异常状态：无。
**体能值**：具体数值可见。奔跑、长时间行走、搬运重物、格斗、使用技能等行为都将减少该数值。可通过休息或物品回复。初始100，每级递增100。
**惊吓值**：以百分比显示，无具体数值。惊吓值高于100%并超过三秒，玩家与游戏的连接将被强制断开，角色被视为已死亡。通过光脑和游戏舱功能，实现对玩家心跳、脉搏、血压、脑神经反应等即时监控，以此测算恐惧的程度。恐惧评级分“浑身是胆”“勇气可嘉”“惊慌失措”“胆颤心惊”“魂不附体”五级，影响额外奖励。
**技巧值**：核心货币之一，具体数值可见。通过解谜、高效战斗、破解世界观等提升游戏效率的行为获取，凡是提升游戏效率的行为皆会奖励技巧值。不可交易，仅可在“惊吓盒子”（系统特殊商店）兑换游戏币或剧本限定物品（属性会调整）。
- **专精系统**：
共六种：格斗、射击、器械、侦查、医疗、通用，等级从 N/A（无法使用该系技能）到 F 及以上，F 级可使用对应技能，发动成功率 20%，等级提升后成功率和效果增强。
专精需通过对应行为解锁（如战斗解锁格斗、摆弄机械解锁器械、解谜 / 观察解锁侦查），无职业限制，玩家可自由发展多专精。
- **装备与技能**：
**装备品质**：分垃圾、破败、普通、精良、完美、传说六级。
- **垃圾**：如“石头”，攻击力微弱，无属性特效
- **普通**：如“生锈的铁钥匙”，基本功能物品
- **精良**：如“血尸必须死”，攻击力较强，至少含一种属性或特效
精良及以上装备至少含一种属性或特效，获取方式以“搜索”为主（剧本场景中寻找），内测后期可通过交易所、套牌系统兑换。
**物品系统**：
- **物品属性结构**：名称、类型、品质、功能、是否可带出该剧本、备注
- **武器属性结构**：名称、类型、品质、攻击力、属性、特效、是否可带出该剧本、备注
- **攻击力分级**：微弱、较弱、一般、较强、强、极强
- **物品获取**：剧本中搜索获得，部分为任务奖励

**技能卡**：分主动（永久掌握、限时拥有、按次数消耗）和被动（永久掌握、限时拥有），需满足对应专精等级才能学习，装备后与角色绑定，技能栏上限 12 格，仅剧本前可调整。
**套牌系统**：可带出剧本的剧情物品会转化为 “拼图牌”，任意凑齐系统判定的 “系列套牌”（如十二生肖、西游相关等），可兑换保底精良级、概率完美级的装备，为无装备玩家提供成长途径。
- **社交与规则**：
社交功能含【最近一起游戏的玩家】【好友】【黑名单】，仅登陆空间可操作好友申请 / 黑名单，非好友仅能通过邮件沟通（24 小时限 3 封，骚扰 / 恐吓邮件会被拦截）。
严格禁止攻击队友（非对抗模式）、语言攻击、性骚扰、歧视等行为，违者将被强制断线、拉黑，严重者永久封停账号并移交公安部门。

### 1.3 世界维度与剧情核心
- **剧本生成逻辑**：剧本由系统基于庞大数据库和玩家记忆碎片随机生成，场景涵盖医院、鬼屋、城市、地窖、走廊、山坡等恐怖主题，融合解谜、战斗、生存元素，难度匹配玩家等级与团队实力。
- **新手教程剧本特点**：包含基础解谜（如寻找钥匙）、基础战斗（使用特定武器对抗怪物）、环境互动（破坏墙壁获取物品）等元素，引导玩家熟悉游戏机制。
剧本存在“世界观破解”机制，玩家解读出剧本背后的设定（如时间循环、诅咒来源等）可获得大量技巧值奖励，部分剧本隐含超自然力量（如超能力、诅咒、恶魔、鬼魂）、平行世界、时间扭曲等设定。

## 二、成长体系与核心规则

### 2.1  等级与称号
- **等级上限**：内测封顶 20 级，升级经验前期按每级递增 100 设定（1-10 级），11 级后经验需求大幅提升（11 级需 11000 经验）。
- **称号系统**：十级解锁，根据玩家表现实时更新，赋予特殊能力（如龙傲 F 的【勇猛的冲锋者】可发动【闪电冲撞】，封不觉的【冷血爆头狂】可触发头部攻击眩晕特效），能力类型含主动、被动，不占用技能栏，是角色个性化的核心体现。

### 2.2 核心规则底线
- **无职业限制**：玩家可自由搭配装备、技能、专精，形成独特战斗 / 解谜风格（如封不觉的 “解谜 + 爆头”，似雨若离的 “近战爆发”）。
- **非显性属性影响**：现实中的身体素质、技能基础（如是否会用枪）会轻微影响游戏内表现（如体能消耗、射击准度），但不影响核心平衡。
- **奖励机制**：经验值分配公平（多人模式幸存者经验一致，坑队友会扣经验），技巧值奖励倾向高效行为（解谜一次性获取多，战斗可累积），惊吓值越低奖励越丰厚。

### 2.3 关键势力
- **系统方**：惊悚乐园游戏运营及其管理AI（中立但不可预测）
- **玩家**：乐子人，网络考古者，靠游戏爱好者。

## 使用说明

1. **创作参考**：此设定为创作者提供完整世界观框架
2. **灵活调整**：可根据具体剧情需要调整细节
3. **渐进揭示**：建议在故事中逐步揭示世界观，保持悬念
4. **角色互动**：不同角色对此世界观应有不同认知和态度
5. **主题深化**：通过具体情节探讨核心主题，避免说教
