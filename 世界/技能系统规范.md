# 技能系统规范

## 一、专精系统规范

### 1.1 专精分类体系

惊悚乐园中共有六项专精，每项专精对应不同的技能类型和游戏风格：

| 专精类型 | 核心能力 | 适用场景 | 初始状态 |
|----------|----------|----------|----------|
| **格斗** | 近战武器、徒手战斗、体术 | 近身战斗、力量对抗 | N/A（新手期未解锁） |
| **射击** | 远程武器、投掷物、枪械 | 远程攻击、精准打击 | N/A（新手期未解锁） |
| **器械** | 机关、陷阱、机械操作、工具使用 | 解谜、环境利用、技术操作 | N/A（新手期未解锁） |
| **侦查** | 观察、搜索、追踪、情报分析 | 线索发现、隐藏物品、环境侦查 | N/A（新手期未解锁） |
| **医疗** | 治疗、急救、药物使用、状态恢复 | 团队支援、生存保障 | N/A（新手期未解锁） |
| **通用** | 基础操作、常识应用、综合能力 | 所有基础游戏操作 | F级（新手期初始解锁） |

### 1.2 专精等级体系

专精等级决定玩家使用对应技能的成功率和效果强度，等级从低到高分为：

| 等级 | 名称 | 技能发动成功率 | 描述 |
|------|------|----------------|------|
| **N/A** | 无 | 0% | 一窍不通，完全无法使用该系技能 |
| **F** | 极差 | 20% | 接近于无，仅能勉强使用基础技能 |
| **E** | 差 | 40% | 略有了解，能够进行简单操作 |
| **D** | 一般 | 60% | 基本掌握，可以正常使用多数技能 |
| **C** | 良好 | 80% | 熟练运用，技能使用稳定可靠 |
| **B** | 优秀 | 90% | 精通掌握，技能效果显著增强 |
| **A** | 卓越 | 95% | 大师级，技能使用近乎完美 |
| **S** | 完美 | 99% | 宗师级，技能效果达到理论极限 |

**示例**：新手教程完成后，玩家通用专精为F级，其他五项专精为N/A状态。

### 1.3 专精成长机制

#### 1.3.1 成长途径
- **技能使用**：成功使用对应专精的技能获得经验
- **任务完成**：完成与专精相关的任务或挑战
- **特殊事件**：剧本中的特殊选择或成就
- **道具辅助**：使用训练道具或特殊物品

#### 1.3.2 成长曲线
- **F→E**：基础熟悉阶段，需要少量实践
- **E→D**：入门掌握阶段，需要系统学习
- **D→C**：熟练运用阶段，需要大量实战
- **C→B**：精通提升阶段，需要专精训练
- **B→A**：大师突破阶段，需要特殊机遇
- **A→S**：宗师达成阶段，极为困难罕见

### 1.4 专精解锁条件

| 专精类型 | 解锁条件 | 新手期状态 |
|----------|----------|------------|
| 通用 | 完成新手教程自动解锁F级 | 已解锁 |
| 格斗 | 成功使用近战武器造成伤害 | N/A |
| 射击 | 成功使用远程武器命中目标 | N/A |
| 器械 | 成功操作机关或机械装置 | N/A |
| 侦查 | 成功发现隐藏线索或物品 | N/A |
| 医疗 | 成功使用医疗物品进行治疗 | N/A |

## 二、技能卡系统规范

### 2.1 技能卡品级体系

技能卡根据稀有度和效果强度分为四个品级：

| 品级 | 获取难度 | 效果强度 | 专精需求 | 备注 |
|------|----------|----------|----------|------|
| **普通** | 常见 | 基础效果 | F-E级 | 新手期主要获取品级 |
| **精良** | 一般 | 显著优势 | D-C级 | 成长期主流品级 |
| **完美** | 稀有 | 卓越效果 | B-A级 | 高级期追求目标 |
| **传说** | 极稀有 | 改变战局 | S级 | 终极收藏品 |

### 2.2 技能卡属性结构

所有技能卡都包含以下属性字段：

```yaml
名称: [技能名称]
类型: [攻击/防御/辅助/特殊]
品级: [普通/精良/完美/传说]
消耗: [体能值消耗，单位：点]
冷却: [冷却时间，单位：秒]
效果: [技能具体效果描述]
专精需求: [所需专精类型及最低等级]
是否可交易: [是/否]
备注: [背景故事、使用技巧或特殊说明]
```

### 2.3 技能分类详解

#### 2.3.1 攻击类技能
- **特点**：直接造成伤害或削弱敌人
- **消耗**：中等至高体能值消耗
- **冷却**：短至中等冷却时间
- **示例**：剑术连击、精准射击、元素攻击

#### 2.3.2 防御类技能
- **特点**：减少伤害、格挡攻击、提升生存
- **消耗**：低至中等体能值消耗
- **冷却**：中等冷却时间
- **示例**：护盾生成、伤害减免、紧急回避

#### 2.3.3 辅助类技能
- **特点**：提供增益、治疗、状态恢复
- **消耗**：低至中等体能值消耗
- **冷却**：长冷却时间
- **示例**：治疗术、速度提升、状态清除

#### 2.3.4 特殊类技能
- **特点**：独特效果、环境互动、剧情相关
- **消耗**：不定，可能消耗特殊资源
- **冷却**：不定，可能为单次使用
- **示例**：机关破解、追踪标记、剧情对话

### 2.4 技能获取机制

#### 2.4.1 主要获取途径
- **剧本通关奖励**：单人生存模式通关后随机获得
- **任务完成奖励**：支线任务、隐藏任务奖励
- **恐惧评级奖励**：高恐惧评级额外奖励
- **技巧值兑换**：使用技巧值在惊吓盒子兑换

#### 2.4.2 获取概率分布
- **新手教程**：100%获得普通品级技能卡
- **训练模式**：不提供技能卡奖励
- **生存模式（普通）**：80%普通，20%精良
- **生存模式（噩梦）**：50%普通，40%精良，10%完美
- **特殊活动**：概率出现完美/传说品级

### 2.5 技能使用规则

#### 2.5.1 发动条件
1. **专精要求**：必须满足技能卡的最低专精等级
2. **消耗支付**：必须有足够的体能值支付技能消耗
3. **冷却状态**：技能必须不在冷却时间内
4. **环境允许**：当前环境允许使用该技能

#### 2.5.2 成功率计算
```
实际成功率 = 基础成功率 × (1 + 专精加成)
专精加成 = (当前专精等级系数 - 需求专精等级系数) × 0.1
```

#### 2.5.3 效果判定
- **成功发动**：技能效果完全生效
- **部分成功**：技能效果减弱或部分生效
- **发动失败**：技能消耗支付但无效果
- **严重失败**：可能产生负面效果

## 三、装备-技能-专精关联规则

### 3.1 装备对技能的加成

#### 3.1.1 武器类型适配
| 武器类型 | 增强技能类型 | 加成效果 |
|----------|--------------|----------|
| 近战武器 | 格斗类技能 | 伤害提升10-30% |
| 远程武器 | 射击类技能 | 命中率提升5-15% |
| 工具类 | 器械类技能 | 成功率提升10-20% |
| 特殊装备 | 对应专精技能 | 特定效果增强 |

#### 3.1.2 防具类型影响
- **重甲**：增强防御类技能效果，但降低移动相关技能
- **轻甲**：平衡防御和移动，适合综合型技能
- **布甲**：增强辅助类技能效果，但防御较低

#### 3.1.3 饰品特殊加成
- **戒指**：可能减少技能冷却时间
- **项链**：可能降低技能体能值消耗
- **护符**：可能提升技能发动成功率

### 3.2 技能对专精的要求

#### 3.2.1 专精等级门槛
- **普通品级技能**：最低F级专精
- **精良品级技能**：最低D级专精
- **完美品级技能**：最低B级专精
- **传说品级技能**：最低A级专精

#### 3.2.2 专精类型匹配
- 技能只能由对应专精类型的玩家学习
- 部分特殊技能可能要求多专精组合
- 通用专精技能所有玩家均可学习

### 3.3 专精对装备的适配

#### 3.3.1 装备使用权限
- **基础装备**：无专精要求
- **进阶装备**：需要对应专精D级以上
- **高级装备**：需要对应专精B级以上
- **传说装备**：需要对应专精A级以上

#### 3.3.2 装备特效触发
- 高专精等级可能解锁装备隐藏特效
- 专精组合可能产生装备联动效果
- 专精等级影响装备使用效率

### 3.4 综合build构建原则

#### 3.4.1 协调性原则
1. **专精聚焦**：选择1-2个主修专精深度发展
2. **技能配套**：选择与专精匹配的技能组合
3. **装备支持**：选择增强技能效果的装备
4. **资源平衡**：平衡体能值消耗和冷却时间

#### 3.4.2 常见build类型
- **战士型**：格斗专精+近战技能+重甲装备
- **射手型**：射击专精+远程技能+轻甲装备
- **技师型**：器械专精+机关技能+工具装备
- **医者型**：医疗专精+治疗技能+辅助装备
- **侦探型**：侦查专精+侦查技能+特殊装备

## 四、平衡性与成长曲线

### 4.1 新手期（1-5级）

#### 4.1.1 专精发展
- **通用专精**：F级，技能成功率20%
- **其他专精**：N/A状态，需要解锁
- **发展重点**：熟悉基础操作，解锁第一个战斗专精

#### 4.1.2 技能获取
- **主要来源**：新手教程奖励、训练模式
- **品级分布**：100%普通品级
- **技能数量**：1-3个基础技能

#### 4.1.3 装备配合
- **武器**：基础近战/远程武器
- **防具**：默认服装，无特殊加成
- **饰品**：无或基础饰品

### 4.2 成长期（6-15级）

#### 4.2.1 专精发展
- **主修专精**：达到D-C级（60-80%成功率）
- **辅修专精**：可能解锁1-2个E级专精
- **发展重点**：专精分化，构建个人风格

#### 4.2.2 技能获取
- **主要来源**：生存模式奖励、任务奖励
- **品级分布**：70%普通，30%精良
- **技能数量**：5-8个技能，开始形成组合

#### 4.2.3 装备配合
- **武器**：精良品质武器，开始有属性加成
- **防具**：获得第一套正式防具
- **饰品**：1-2个功能饰品

### 4.3 高级期（16-20级）

#### 4.3.1 专精发展
- **主修专精**：达到B-A级（90-95%成功率）
- **专精组合**：可能掌握2-3个C级以上专精
- **发展重点**：专精通关，技能组合优化

#### 4.3.2 技能获取
- **主要来源**：噩梦模式、隐藏任务、套牌兑换
- **品级分布**：40%普通，50%精良，10%完美
- **技能数量**：10+个技能，完善技能体系

#### 4.3.3 装备配合
- **武器**：完美品质武器，强特效
- **防具**：套装防具，套装加成
- **饰品**：3-4个高级饰品，形成配合

## 五、设计原则与示例

### 5.1 技能设计核心原则

#### 5.1.1 平衡性原则
- **风险收益平衡**：强效果对应高消耗/长冷却
- **专精门槛合理**：品级越高，专精要求越高
- **环境适应性**：技能在不同剧本中应有不同价值

#### 5.1.2 独特性原则
- **效果独特**：每个技能应有明确特色
- **视觉辨识**：技能发动应有明显视觉特征
- **战术价值**：技能应有明确的战术应用场景

#### 5.1.3 实用性原则
- **使用频率**：技能应有合理的出场机会
- **学习曲线**：技能复杂度与品级匹配
- **组合潜力**：技能应能与其他技能/装备组合

### 5.2 专精成长示例：封不觉的通用专精

#### 5.2.1 成长轨迹
1. **新手教程完成**：通用专精解锁，达到F级（20%成功率）
2. **多次剧本实践**：通过使用通用技能积累经验
3. **专精等级提升**：F→E→D级逐步提升
4. **技能成功率**：从20%提升至60%

#### 5.2.2 成长关键点
- **首次成功使用技能**：建立专精使用基础
- **连续成功使用**：加速专精经验积累
- **高难度成功使用**：提供大量专精经验
- **特殊成就达成**：可能直接提升专精等级

### 5.3 技能卡示例分析

#### 示例1：基础攻击技能（普通品级）
```yaml
名称: 重击
类型: 攻击
品级: 普通
消耗: 20点体能值
冷却: 10秒
效果: 对目标造成一次强力打击，造成基础攻击力150%的伤害
专精需求: 格斗专精 F级
是否可交易: 是
备注: 最基础的近战攻击技能，适合新手玩家学习战斗节奏
```

#### 示例2：侦查辅助技能（精良品级）
```yaml
名称: 鹰眼视觉
类型: 辅助
品级: 精良
消耗: 15点体能值
冷却: 30秒
效果: 提升侦查能力，持续10秒内更容易发现隐藏线索和物品
专精需求: 侦查专精 D级
是否可交易: 是
备注: 侦探型玩家的核心技能，在解谜剧本中价值极高
```

#### 示例3：特殊剧情技能（完美品级）
```yaml
名称: 剧情洞察
类型: 特殊
品级: 完美
消耗: 50点体能值
冷却: 300秒
效果: 在剧情关键点使用，可获得额外剧情线索或选项
专精需求: 侦查专精 B级 且 通用专精 C级
是否可交易: 否
备注: 稀有剧情类技能，可能改变剧本走向或解锁隐藏结局
```

### 5.4 build构建示例：智力型解谜者

#### 5.4.1 专精配置
- **主修**：侦查专精（C级）、器械专精（C级）
- **辅修**：通用专精（D级）
- **未修**：格斗专精（E级）、射击专精（N/A）、医疗专精（E级）

#### 5.4.2 技能组合
1. **核心技能**：鹰眼视觉（侦查）、机关破解（器械）
2. **辅助技能**：快速思考（通用）、紧急包扎（医疗）
3. **备用技能**：基础闪避（格斗）

#### 5.4.3 装备搭配
- **武器**：多功能工具刀（增强器械技能）
- **防具**：轻便探险服（提升移动和侦查）
- **饰品**：放大镜挂坠（提升侦查成功率）

#### 5.4.4 战术应用
- **解谜场景**：使用侦查技能发现线索，器械技能破解机关
- **战斗场景**：避免正面战斗，使用环境优势和紧急技能
- **团队场景**：提供侦查支持，辅助队友解谜

## 八、使用说明

### 8.1 文档定位
本文档是《惊悚乐园》游戏系统中技能相关规则的详细规范，主要服务于：
- **游戏设计者**：设计新技能、平衡专精系统
- **剧本作者**：创作符合游戏规则的剧本内容
- **玩家参考**：理解游戏机制，优化角色build

### 8.2 核心要点
1. **专精是核心**：专精等级决定技能使用成功率和效果
2. **技能分品级**：普通、精良、完美、传说四个品级
3. **装备要配套**：选择与专精和技能匹配的装备
4. **成长有阶段**：新手期、成长期、高级期不同发展重点

### 8.3 设计原则提醒
1. **平衡性优先**：避免某个技能或专精过于强势
2. **独特性保证**：每个技能应有明确特色和应用场景
3. **关联性考虑**：装备、技能、专精三者要协调设计
4. **成长性规划**：确保玩家有明确的成长路径和目标

> **注意**：本文档内容基于游戏内测阶段设计，公测时可能根据玩家反馈和平衡性测试进行调整。
